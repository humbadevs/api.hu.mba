# Get started
To run the api on localhost do the following steps:
```bash
# Clone the repository onto your local machine
git clone https://github.com/humbadevs/api.hu.mba.git
cd api.hu.mba
# Install packages
npm i
# start local app
node server.js
# voilà 🎉
```
